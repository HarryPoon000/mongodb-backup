# mongodb-backup

[`bkup.sh`](bkup.sh): Back up a mongodb database using the database URI

[`restore.sh`](restore.sh): Restore to a mongodb database from stored backups

## Dependencies
`mongodb-database-tools` [(installation guide)](https://www.mongodb.com/docs/database-tools/installation/)
 - [`mongorestore`](https://www.mongodb.com/docs/database-tools/mongorestore/)
 - [`mongodump`](https://www.mongodb.com/docs/database-tools/mongodump/)
